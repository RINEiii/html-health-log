## 我的体会：怎么给 AI 提修改意见

- **用截图框选，不只靠文字**：把页面截图，用不同颜色的框标出问题。同一类问题（比如阿拉伯数字字体）在不同页面用同一种颜色，不同的问题用不同颜色，让 AI 分得清哪些是同一件事。
- **用取色代替形容词**：在醒图里选好色块，直接给 AI 看，而不是说"亮一点""暖一点"。v03 我只说了"颜色明显一点"，结果调过头；后面给了具体颜色，才调回来。
- **给例图（类似 few-shot）**：想要的效果找一张参考图给它，比如手机时钟的数字排版、某网页的渐变。
- **AI 做不对时判断要不要放弃**：v04 水波纹，效果不像还变卡，我就放弃了，没有硬磨。
- **嵌图会让体积暴增**：v17 嵌了数字图，文件从 56KB 涨到约 520KB，下次可以考虑用字体代替。
